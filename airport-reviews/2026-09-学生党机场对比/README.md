## 口径与权重

价格与条款采集自各站**官方店面、官方文档、FAQ** 页面（2026 年 9 月），少数项来自第三方公开测评并已标注来源层级；标 ★ 的是博主自费在用、信息来自本人后台。

**速度类结论只来自个人有限使用，未做标准化测速——所以本系列不给测速数字，只给测法**（见第六节）。这一点连机场自己都同意：赔钱机场 FAQ 写着"延迟仅为可用性参考，并不绝对，请不要用来作为速度及是否好用的绝对参考"。

权重：**价格 25% / IP 纯净度 25% / 晚高峰速度 20% / 地区覆盖 10% / 稳定性与售后 15% / 客户端易用性 5%**，各维 1–5 分。风险不占权重，只做两件事：**一票否决**（已停运或客服失联者出池——echo 即因此删掉）与**分数封顶**（曾进跑路名单或频繁换域名者，售后分上限 3 分）。

## 三、为什么便宜必然降智（机制）

**晚高峰为什么堵。** 国际出口 20:00–23:00 拥塞是物理事实，正价机场靠 IEPL / 中转专线绕开这一段，而**一条专线的月租就超过低价站全年营收**。一元机场官方那句「采用全球知名公有云月抛作为主力节点，成本远远低于大多数机场……放心不会跑路，如果担心可以月付」已经把账算给你看了：它买的不是带宽，是云厂商的按量额度，**没有"优化"可言，只能等高峰过去**。所以社区说一元"最好的时候是早上 6 点到下午 3 点"，这不是运气，是成本结构。**这一点连机场自己都承认**：SakuraCat 文档给出三类线路的官方体验排序 **IEPL 专线 > 中转 > 直连**，并写明直连"晚高峰可能出现延迟、抖动或速度下降"、中转"晚高峰通常比直连更稳定"。问题从来不在节点在哪个国家，在于你有没有钱买绕开拥塞那一段的线路。

**带宽成本怎么转嫁给你。** 三种写法都在本表：① **倍率换算**——精灵学院电信用户亚洲节点 2×，同一份带宽多收一倍；② **时段引导**——SakuraCat 凌晨流量减半（官方注明只是流量扣除比例，不减网速、不改套餐价），把你挪到空闲时段，省的是它的钱；③ **配额封顶**——赔钱每天只放总量 10%。**看价格必须换算成"我的运营商 × 我常用地区 × 单 GB 实付"，标价是营销位；所谓"无限流量"，凡是没给你具体 Mbps 或具体日配额的，都是无限扣你的钱。**

**超低价为什么对应脏 IP。** 平台不看你是谁，看 IP 属于哪个 ASN。AWS、GCP、Oracle、Cloudflare 这些段被大规模滥用过，于是要么整段限流、要么强制验证。吹雪云是最干净的证据：22 个出口全是 Amazon 与 Cloudflare、无一家宽，同时它也是最便宜的站之一——**这两件事不是巧合，是同一件事**。同一个 IP 段上万人共用，平台看到的就是你在一遍遍换地区，降智与强制验证由此而来。**便宜站的 AI 可用性是临时状态，不是产品承诺。** 反过来，"干净 IP 值多少钱"，飞猫云的店面自己标了价：普通宇宙版 ¥150/月·1TB 约 **¥0.15/GB**，而 ¥550/月·500G 的定制套餐（写明"独享原生 IP""每人独立宽带"）是 **¥1.1/GB——贵 7 倍**。这七倍就是"不跟别人共用出口"的市场价。而 [苏菲家宽](08-苏菲家宽.md) 补上了中间那一档：真住宅 IP，但**每车最多 20 人共用**，¥20/月·250G 约 ¥0.08/GB——**比机房贵、比独享便宜 14–18 倍**。把三家摆在一起，"干净 IP"的价格阶梯就很清楚了：**万人共用的机房出口 ¥0.002–0.003/GB → 20 人拼车的真住宅 IP ¥0.06–0.08/GB → 独享原生 IP ¥1.1/GB**。你付出的价差，买的就是"这条线上还有几个人"。

## 四、避坑清单

- **只卖年付 / 最低价档必须长买**：飞猫云最低价 ¥84 是年付且须一次结清；SakuraCat 无试用又无原路退款。
- **划线价与"重置 ≠ 续费"**：赔钱机场每档都挂划线原价（¥9→¥5.99、¥49→¥12.99），"限时特惠"是常态，**折扣感是设计出来的**；其 FAQ 另有一条容易吃亏的规则——**重置包要已用流量超 80% 才能买、只清空当期已用不延长周期，续费只延长周期不清流量**。
- **无公开状态页**：★ 面板实见一元机场左侧导航有"节点状态"，但要登录才可见；公开可读的只有赔钱机场 `status.pqjc.site`（且被 Cloudflare 挡住），其余全靠 TG 频道。"99.9% 可用性"这类自述数字没有第三方口径可核。
- **换域名与仿冒站（最高危）**：一元系入口后缀特别多（`.com` / `.asia` / `.top` / `.ink` / `.xyz` / `.vip`，以及数字开头的 `1元机场.com`），本文所用入口的面板三档与第三方记录的官方套餐完全一致，应属同一运营方的多入口之一；但 `一元机场.cc` 已落入广告变现网络，`p6p.net` 那个"官网入口发布页"17 个按钮全跳别家并带对方邀请码。SakuraCat 官方 2026-06-05 的入口清单里 c1/c2 已被 c3/c4 替换，**`sakuracat.org` 是官方点名警告的盗版站**（下载链跳去别家产品、把 ¥ 写成 $、承诺官方否认的试用与退款）；精灵学院 2026-08-01 刚换过域、另有 `ejen.org` 自挂"官方网站"。**下单前以官方 TG 公告频道列出的域为准，不要认搜索引擎第一条。**
- **节点数注水**：赔钱约 100 个 vs 另一来源 62 个；飞猫云 69 vs 88；精灵学院从 42 精简到 15 又回到 25。**节点标签数 ≠ 独立出口 IP 数。**
- **协议与端口限制（学生最容易踩）**：便宜站靠砍 UDP 和非常规端口省成本。吹雪云官方文档自认 UDP 走 UoT 封装、默认屏蔽纯 IP 与 22/25/53 等端口；赔钱机场"购前须知"也明写"有限制非 443 端口"。**打游戏、Discord 语音、SSH 隧道、直连数据集镜像之前，先翻它的文档页。**
- **白嫖试用后强推年付**：试用（吹雪云 7 日、Runway 1 天）是拿来验证线路的，验证完先月付。
- **行业背景**：跑路名单仓库 2026-04 记「上游拔线仍在继续，中转机场已无更多线路可用」，并写下「**购买任何机场，务必仅月付**」；08 月记「7–8 月情况大幅缓解」。这不是某家的问题，是整轮的。

## 五、一个数据观：第三方测评为什么不可信

本系列在采集时踩到的坑，值得单独写出来：

- **几乎所有"机场测评站"都自带邀请返佣声明**，它们的"测速数据"不是独立实测，是竞争者的广告位。价格可以引（是公开事实），"好用 / 稳定"的结论不能引。
- **同一站不同来源能给出四套互斥价格表**（飞猫云），流量档位在 50 / 80 / 100 / 150 / 200 / 300 / 350 / 500 / 600 / 1000GB 之间漂移。
- **一家测评站的两篇文章互相推翻自己**：一篇写"我们晚上 22:00 用联通 1000M 宽带批量测速、未观察到丢包"，另一篇同作者同日期却列"测试日期未记录、网络未记录、原始日志未取得"，并把全部测速降级为"仅服务商资料"。
- **速度数据根本不可迁移**：别人在张家口电信 1Gbps 入口测的数，放进你的文章就是造假。
- **蹭牌与冒名是常态**：`sakuracat.org`、`ejen.org`、`p6p.net`、`peiqianjic.club`（把赔钱机场写成 2020 年创立的 IPLC 专线老牌机场）——**四个"官网"里没有一个是那家**。

所以本系列的做法是：**能拿到官方店面 / 文档 / 面板实见的，标"官方实见"；只有第三方说的，标来源与"返佣站"；只有我自己测的，标 ★ 并写明不可复核。** 拿不到的，宁可留白。

## 六、30 分钟自己验一个站（不用买年付）

1. **先数独立 IP，不是数标签**：买月付最低档导入 Mihomo，逐节点访问 `ip.sb` 抄下出口 IP 去重。20 个标签对应 3 个 IP 就是注水。
2. **查 IP 类型**：拿这些 IP 去 `ipinfo.io` 与 scam-analytics 看两个字段——**ASN 是否 AWS / GCP / Oracle / Cloudflare**（是 → 大概率整段打标）、**Connection type 是 Hosting 还是 ISP / 固宽**（住宅出口通常显示为具体宽带商）。若某站自称家宽，**用它自己指定的工具验才算同口径**：苏菲家宽条款写明 IP 质量"以 **ipdata.co** 和 **IPcheck 脚本**检测为主，部分参考 **ping0.cc**"，并声明对其他第三方工具的结果不负责。
3. **AI 侧自查**：打开 `chatgpt.com/cdn-cgi/trace` 看 `loc=` 是否等于你选的落地地区（不等于说明 IP 在乱跳）；让模型报当前日期看有无降级；**一旦出现手机号验证或 `unsupported_country`，立刻停手，重要账号不要挂在这条线上。**
4. **必须在 20:00–23:00 做**：同一 prompt 连测三次首 token，看抖动而不只看均值；用 fast.com 记 YouTube 实际码率而非 Speedtest 峰值。**白天数据没有参考价值**，本表所有速度分只按晚高峰打。
5. **校园网与家用各测一次**：走 Hysteria2 的线路在校园网最常见的死法就是完全连不上。
6. **测 UDP 与端口**：`ssh -p 22` 连任意公网主机、开一次 Discord 语音、直接访问一个纯 IP 站点。这三项被屏蔽是便宜站的常规操作（本表里吹雪云三项全中），**而机场未必把这类限制写在显眼处**。

## 七、另册：两个不进打分表的

有两家的产品形态与机场不同，**硬套那套权重会造出假可比**，所以单独成篇、只给定位：

- **[迷雾通（Geph）](07-迷雾通.md)** —— 开源抗审查系统，不是机场。两个独特点：**授权绑定设备而非账号**（"仅限本人"在这里是机制，不像某些站只写在套餐卡上），以及**全系列只有它能被读者自己到 GitHub 上查证**——本篇用 API 实查了许可证与提交时间，结果是"客户端历史代码确为 GPL-3.0，但当前活跃线 `geph5` 未声明许可证、服务端本就不开源"，**能查，但比宣传的弱**。月付基础版 €1.1 起（全系列最低门槛），但**三个月档零折扣**、年付只省 8.8%，所以按月买即可。适合当**兜底通道**与机场并备，不适合替代机场（不可选出口地区、无流媒体保障）。
- **[苏菲家宽](08-苏菲家宽.md)** —— 住宅 IP 代理，按"车"卖。23 个套餐里**只有 4 档"上网套餐"是学生党该看的**（¥3 起，普通机场线路），其余 18 档是**最多 20 人共用一个真住宅 IP** 的拼车，为 TikTok 直播与跨境电商设计，延迟高且降不下来（流量要先反代到某户人家的住宅宽带）。它的条款里有一句全系列最诚实的话：**AI 降智"与浏览器指纹、账号是否共享关系极大，本站对此无法做出任何保证"**。

**一句话分别**：连不上找迷雾通，被风控找苏菲，日常用还是那 6 家机场。
