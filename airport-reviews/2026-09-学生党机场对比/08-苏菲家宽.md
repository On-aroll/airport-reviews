## 二、"拼车"到底是什么意思（这是全文最关键的一节）

官方服务条款第一条写得很清楚：

> 每个家宽 IP 套餐**最高限定 20 人共同使用，实际每日活跃人数约为 7–8 人**。套餐满员后自动下架，月末有人下车才重新上架。

所以 ¥20/月 买的是**一个真住宅 IP 的 1/20 使用权**。这就解释了它的价格结构，也解释了它的局限：

- **好的一面**：住宅 IP 不在 AWS / Cloudflare / Oracle 那批被整段打标的 ASN 里，所以平台侧的"整段限流"对它不成立。这正是本系列前几篇反复说的"机房 IP 为什么会降智"的反面。
- **要留神的一面**：**"20 人共用"和"独享"是两回事。** 拿本系列另一家做对照最直观：飞猫云的定制套餐 ¥550/月·500G，写明"独享原生 IP""每位用户分配独立宽带与 IP"，即 **¥1.1/GB**；苏菲的家宽拼车是 **¥0.06–0.08/GB**。**差 14–18 倍，差的就是"这条线上有没有别人"。**

## 三、关于"降智"，这是全系列我见过最诚实的一段官方话术

条款第三条原文（照录）：

> 关于 AI 降智缓解，**浏览器指纹暴露、位置暴露以及共享账号等情况都可能导致 AI 平台（如 ChatGPT）降智**或其他网站服务限制，**使用家宽 IP 可能有所缓解，但是与浏览器指纹、账号是否共享关系极大，本站对此无法做出任何保证**。

**这句话应该被所有机场测评引用。** 它承认了三件事：① 换 IP 只是"可能有所缓解"，不是解决；② 你自己的浏览器指纹和共享账号才是主因；③ 官方不做任何保证。

对照本系列其他站的说法——"稳定解锁 TikTok、ChatGPT 等"（赔钱机场店面文案）、"原生 IP 线路，轻松解锁 Netflix、Disney+、ChatGPT、TikTok"（飞猫云）、"流媒体 AI 解锁，请以实测为准"（吹雪云）——**只有苏菲把"这不怪 IP，也怪你"写进了条款**。便宜站里这种克制很少见。

**校园网用户特别注意**：hy2 会被运营商阻断、ss 直连不可用——**这两条是官方自己写的**，比任何"校园网能不能用"的猜测都可靠。

## 五、延迟高是设计如此，不是你的问题

FAQ 第一条：

> 有些家宽 IP 节点，**必须用一台服务器去反代连接真实住宅网络中的设备**，由于家宽网络连接不稳定等原因，延迟相对会比较高，且很难降低。但是延迟和网络带宽并不相关，您仍可享受高速网络带宽。

**这就是家宽代理的真实形态**：你的流量先落到一台反代服务器，再经由某户人家的住宅宽带出网。多一跳，延迟必然高，且**降不下来**。所以如果你要的是低延迟游戏，家宽不是选项；如果你要的是"平台眼里我像一个正常美国家庭用户"，那这一跳就是它的价值。

## 六、其余条款要点

- **IP 类型**：官方称包含"真实家庭宽带 IP、AT&T 住户商业宽带 IP 及住宅代理 IP"——注意**"住宅代理 IP"和"真实家宽"不是一回事**，条款用"包含但不限于"带过，上车前问清楚是哪一种。
- **官方指定的检测口径**：IP 质量"以 **ipdata.co** 和 **IPcheck 脚本**检测为主，部分参考 **ping0.cc**"，并声明对其他第三方工具的结果不负责。**用它给的这三处验它，才算同口径。**
- **换车**：随时可申请换车队，**当前月套餐剩余价值自动抵扣，只补差价**。这条对"分到的 IP 不满意"很实用。
- **退款**：一般不接受；**只有在"受攻击或连续无法使用超过 7 天且无法提供有效替代 IP"时，按最高 15 天剩余价值退**，且**退款只支持 USDT**（链上或币安）。条件苛刻但比"完全不退"具体。
- **不提供 SLA**，条款保留随时修订权利、恕不另行通知。

## 七、适合谁

| 适合 | 不适合 |
| --- | --- |
| **TikTok 直播 / 跨境电商 / 社媒矩阵**（这才是家宽的目标场景） | 以为"买了家宽 AI 就不降智"的人（官方自己说不保证） |
| AI 账号频繁被风控、已排除线路原因、怀疑是机房 IP 所致 | 要低延迟打游戏的（反代架构决定延迟高） |
| 需要指定运营商出口（AT&T / Verizon / T-mobile / 康卡斯特 / frontier / KDDI / 星链） | 校园网重度用户（hy2 被阻断、ss 需中转） |
| 只想花 ¥3 试一个月的学生（体验版 66G / 2 台） | 需要退款保障、不想用 USDT 的人 |

**给学生的直接建议**：先看上网套餐那四档，那是普通机场线路；**除非你明确知道自己需要住宅 IP，否则不要为"家宽"两个字多付钱**。

## 八、为什么不进打分表
