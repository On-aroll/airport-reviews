## 二、最该记住的两条限制（来自它自己的文档，更新于 2026-09-19）

1. **UDP 采用 UoT（UDP over TCP）再封装，不是标准原生 UDP。** 官方文档逐条列了后果：*"可以更新游戏，但无法进入游戏""可以进入游戏，但无法进入房间""手机端 Discord 可以用，电脑端无法通话"*，并说明这属"传输方式不兼容的正常现象，并不一定代表节点失效"。**官方给的解决建议是：更换支持标准 UDP 的机场，一般协议为 SS 或 AnyTLS。**
2. **默认屏蔽纯 IP 地址与带端口访问**，并屏蔽 21 / 22 / 23 / 25 / 53 / 110 / 135–139 等高危端口。要访问纯 IP 站点，得先给它加个域名。

**翻译成人话**：打竞技游戏、用 Discord 语音开黑、`ssh -p 22` 连学校服务器、跑自建服务的人，**这两条比任何测速数字都重要，直接排除这家**。

## 三、纯净度：它为什么能这么便宜

第三方实测 22 个出口全是 VLESS，**入口与出口 ASN 清一色 Amazon（AS16509 / AS14618）与 Cloudflare（AS13335）**，即云机房 IP，**无一家宽**。这解释了它的定价，也解释了它的解锁表现：同一批实测里 OpenAI 与 Claude 在日 / 新 / 台 / 韩 / 美 / 英 / 德解锁，**香港 4 条全部失败**，HBO Max 全失败。

解锁机制官方也说了：走 **DNS 解锁**，承认"可能存在掉解锁或者只解锁自制剧的情况"；支持对象列 Netflix、Disney+、YouTube、哔哩哔哩、**OpenAI（不包含 Codex）**、TikTok，其他平台不承诺覆盖；**机顶盒、电视机、游戏机、ATV 不解锁**。

**云机房出口 + 便宜，这两件事不是巧合，是同一件事。**
