## 四、怎么买，买完什么时候重置

按 9 月面板记录，免费版在月初刷新，常规 VIP 从购买日起每 30 天刷新，剩余流量随周期清零。**重新买套餐会直接替换旧套餐的剩余权益**。例如当前还有 10 天、80 GB，提前下新单前先看后台是否提示覆盖，确认新周期从哪天开始。[重置与购买规则记录](https://www.jichangtuijian.live/pianyijichang/ikuuu)

注册页指向的原始服务条款写明没有退款机制。免费测试可以先确定账号能否正常登录、订阅能否更新。若目标是香港等付费节点，再用当时可买的最短周期验证该线路。9 月面板的使用限制列有 BT、游戏、TikTok 等场景，需按现行说明确认支持范围。[iKuuu 服务条款](https://ikuuu.top/tos) · [面板使用说明记录](https://www.jichangtuijian.live/pianyijichang/ikuuu)

## 五、注册、客户端与常见故障

注册页有邮箱验证码流程。文档中心标出的主域名是 `ikuuu.top`，域名发布页也列出 `ikuuu.pw`。遇到旧链接失效，可以先用发布页核对入口，再从账号中心选客户端或订阅格式。[iKuuu 域名发布页](https://ikuuu.pro/) · [iKuuu 文档中心](https://docs-2.ikuuu.live/)

| 设备 | 官方文档中可查到的订阅更新方式 |
| --- | --- |
| Windows | Clash for Windows 的配置页可以刷新订阅，文档要求刷新前暂停系统代理 |
| Android | Clash for Android 先暂停连接，再从配置菜单更新 |
| macOS | ClashX 先关闭系统代理，再更新托管配置 |
| iPhone / iPad | Shadowrocket 从配置列表刷新，完成后恢复代理 |

9 月面板记录还见到可直接登录的 iKuuu VPN 客户端，以及 Clash、Shadowrocket 和 SS 等订阅入口。上表对应文档里的客户端版本，首次安装和可导出的格式以账号中心为准。使用 Mihomo 等兼容客户端时，可从面板选 Clash 格式，先验证订阅能否读取和刷新，再测试连接。[客户端面板记录](https://www.jichangtuijian.live/pianyijichang/ikuuu) · [Mihomo 代理集合文档](https://wiki.metacubex.one/config/proxy-providers/)

**排查按顺序做**。订阅刷不出时先查登录域名和账号状态。列表能刷新、所有节点却都超时，再确认系统时间同步、剩余额度和当前网络。只有一个网站访问失败时，记录选中的节点与出口地区，再用同地区的第二条线路复核。登录页另列有邮箱验证码帮助和管理员联系方式。[登录与故障帮助](https://ikuuu.top/auth/login)

## 七、用一次小测试判断是否适合自己的网络

1. **测入口**。同一台电脑分别用校园网和家用宽带或手机热点登录、刷新订阅，记录失败发生在登录、更新还是连接节点。
2. **测常用任务**。固定同一个节点和同一个任务，例如打开 GitHub 仓库并拉取同一份小文件。白天和 20:00–23:00 各做一轮，记成功、超时或中断。免费日本与 VIP 日本需要各测各的。
3. **测扣量**。只保留一台测试设备，记下测试前后的面板已用流量。等待面板刷新后核算差值，再和节点标出的倍率比对。
4. **测出口和目标服务**。核对出口地区、ASN 和 IP 类型。AI 的登录、对话与 API、流媒体的首页与实际播放各记一项。外部探针能访问入口，只能说明它在当时的测试条件下达到了该步骤。
