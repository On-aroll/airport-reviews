## 约定

- **★** 标记的内容为博主自费在用、信息来自本人后台或实测，未经第三方核验。
- 无法核实的数据一律写成"来源冲突，不采信"或"无公开数据"，**不用同类机场的常识补齐**。
- 速度类结论只给测法、不给数字：不同城市、运营商、入口带宽下测出的数不可迁移。
- **另册**：产品形态与机场不同（抗审查系统、住宅 IP 代理），不套用打分权重，只给定位与适用场景。
- 链接标签统一为"官方网址"（指向官方域名的注册页）；返佣披露只放在文末一处。
- 每个系列目录下的 `_archive/` 是历史版本，仅供追溯，不对外发布。
